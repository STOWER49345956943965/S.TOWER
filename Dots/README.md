# Dot configuration

Every discovered family has its own `.js` file in this folder. Edit its exported object:
- `discovered`: true/false controls whether profile details are public.
- `color`: the dot glow and route color.
- `daysAway`: distance in days from the currently searched family.
- `badge.uri`: badge image URI shown beside the name and in the profile.
- `bannerUri`, `lore`, `members`, `elevations`: profile content.

To add a family, create another config file and register it in `src/data.js`.
Undiscovered procedural dots are generated by the map and reveal only their distance.
